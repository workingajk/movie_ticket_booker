# Movie Ticket Booker

A multi-page movie and theater booking interface built with HTML, CSS, and JavaScript. The pages cover movies, shows, theaters, users, settings, and booking.

## Tech Stack
- HTML5
- CSS3
- JavaScript

## Run Locally
Clone or download this repository and open `index.html` in a modern browser. No build step is required for the static frontend.

## Project Structure
- `index.html` — main page
- `movies.html`, `shows.html`, `theaters.html` — movie and theater pages
- `booking.html` — booking page
- `users.html`, `settings.html` — supporting interface pages
- `css/`, `js/`, `img/` — styles, scripts, and image assets
